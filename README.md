# Diplomatura en Blockchain · LICDIA UNLu 2026

🔗 **Sitio en vivo:** https://dpetrocelli.github.io/blockchain-dev/

## Contenido

- [`index.html`](index.html) — Landing principal: programa, perfil, stack, equipo, aranceles, inscripción.
- [`plan-de-estudios.html`](plan-de-estudios.html) — Plan detallado: 4 módulos · 12 clases · proyecto integrador · bibliografía.
- [`guia-presentacion.html`](guia-presentacion.html) — Guía interna para el equipo docente: guion slide-by-slide del deck + FAQ + manejo de objeciones.
