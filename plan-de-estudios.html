Plan de estudios

Diplomatura de Posgrado · 4 módulos · 4 meses · cursado sincrónico online (miércoles 19–22hs ARG) con grabaciones disponibles. Defensa de proyecto integrador frente a tribunal.

Módulo 1 · Fundamentos teóricos

Base conceptual y herramientas para empezar a trabajar con blockchain.

CLASE 1
Introducción a blockchain y criptografía
🔓 Hash, bloques, consenso
🏫 Contenidos
¿Qué es una blockchain? Hash criptográfico (SHA-256). Estructura de bloques. Algoritmos de consenso (PoW vs PoS). Bitcoin vs Ethereum.
🛠 Práctica
Setup MetaMask + faucet de Sepolia. Primera transacción on-chain. Exploración de Etherscan.
CLASE 2
Ethereum, EVM y arquitectura L1/L2
🔓 EVM · gas · escalabilidad
🏫 Contenidos
Ethereum Virtual Machine (EVM). Modelo de cuentas. Gas y fees. Layer 1 vs Layer 2 (Base, Arbitrum, Optimism). Rollups, sidechains, validation proofs.
🛠 Práctica
Comparativa de gas en distintas L2s. Análisis de transacciones reales en Etherscan + L2 explorers.

Módulo 2 · Solidity y Foundry

Desarrollo de smart contracts con el toolchain estándar de la industria.

CLASE 3
Solidity desde cero
🔓 Tipos · funciones · storage
🏫 Contenidos
Sintaxis Solidity. Tipos de datos. Visibilidad (public/private/internal/external). State variables vs locales. Storage vs memory vs calldata.
🛠 Práctica
Implementar SimpleStorage. Modificar setters/getters. Probar en Remix.
CLASE 4
Foundry — desarrollo y testing
🔓 forge · anvil · cast
🏫 Contenidos
Setup Foundry. forge build, forge test, forge script. Anvil (blockchain local). Cast (CLI para interactuar con contratos).
🛠 Práctica
Migrar SimpleStorage a Foundry. Escribir 10 tests. Deploy local con Anvil.
CLASE 5
Patrones de diseño en Solidity
🔓 Modifiers · events · errors
🏫 Contenidos
Modifiers (onlyOwner, onlyAfter). Events e indexing. Custom errors. Receive y fallback functions. Patrones: Ownable, Pausable, Pull-over-Push.
🛠 Práctica
Sistema de votación con eventos, modifiers y access control básico. Tests de cada flujo.

Módulo 3 · Estándares ERC y NFTs

Tokens fungibles y no fungibles. Despliegue en redes públicas.

CLASE 6
OpenZeppelin y ERC-20
🔓 Tokens fungibles
🏫 Contenidos
Librería OpenZeppelin Contracts. Estándar ERC-20: implementación, hooks, extensiones (Burnable, Pausable, Permit). Casos de uso: stablecoins, governance tokens.
🛠 Práctica
Crear tu propio ERC-20 con OpenZeppelin. Deploy en Sepolia. Verificar en Etherscan.
CLASE 7
ERC-721 y NFTs
🔓 Tokens no fungibles
🏫 Contenidos
Estándar ERC-721. Metadata on-chain vs off-chain. IPFS para storage descentralizado. Casos: arte digital, coleccionables, certificados, identidad.
🛠 Práctica
Implementar AcademicCredentials — NFT para certificados académicos. Mint, transfer, burn. Tests completos.
CLASE 8
Soulbound Tokens y AccessControl
🔓 SBT · roles · permisos
🏫 Contenidos
Soulbound Tokens (no transferibles). AccessControl de OpenZeppelin: roles granulares (DEFAULT_ADMIN, ISSUER, REVOKER). Casos reales: KYC on-chain, credenciales no transferibles.
🛠 Práctica
Extender AcademicCredentials con AccessControl + soulbound. Multi-issuer. Revocación de credenciales.

Módulo 4 · Frontend Web3 y Seguridad

Conectar smart contracts con interfaz de usuario. Auditoría y vulnerabilidades.

CLASE 9
Frontend Web3 con Next.js
🔓 wagmi · RainbowKit · ethers
🏫 Contenidos
Setup Next.js 14 + TypeScript. wagmi (hooks Web3 para React). RainbowKit (UI de conexión wallet). ethers.js v6: providers, contracts, signers. Read vs write transactions.
🛠 Práctica
Frontend para interactuar con AcademicCredentials. Conectar wallet, leer credenciales, mintear nuevas.
CLASE 10
Auditoría de seguridad
🔓 Slither · CEI · ReentrancyGuard
🏫 Contenidos
Top 10 vulnerabilidades Solidity. Reentrancy attacks (caso DAO). Patrón Checks-Effects-Interactions (CEI). ReentrancyGuard. Integer overflow. Front-running. Slither — análisis estático automatizado.
🛠 Práctica
Romper un contrato vulnerable en Anvil. Aplicar CEI. Pasar Slither sobre tu contrato y resolver findings.
CLASE 11
Deploy en L2 (Base Sepolia)
🔓 Bridges · gas · monitoring
🏫 Contenidos
Diferencias L1 vs L2 en deploy. Faucets de Base Sepolia. Verification en BaseScan. Bridges (oficiales y de terceros). Costos comparados.
🛠 Práctica
Migrar tu sistema completo a Base Sepolia. Verificación pública. Frontend conectado a la L2.
CLASE 12
Casos de uso reales y aplicaciones sectoriales
🔓 DeFi · DAOs · RWA · regtech
🏫 Contenidos
DeFi (Uniswap, Aave, MakerDAO). DAOs y governance on-chain. Tokenización de activos reales (RWA). Stablecoins (USDC, wARS de Ripio). Regtech: KYC on-chain, AFIP cripto.
🛠 Práctica
Análisis de un protocolo DeFi real (lectura de código + auditoría externa). Definición del proyecto integrador.

Proyecto integrador final

DEFENSA FRENTE A TRIBUNAL

Sistema de verificación de credenciales académicas con SBT

Extender AcademicCredentials con AccessControl + Soulbound + struct completo de credencial. Frontend con 2 modos obligatorios (verificador público + issuer) y un 3.° opcional (super-admin) por bonus. Deploy en Base Sepolia (L2). Documentación audiovisual de demo end-to-end.

📅 Defensa al cierre de la diplomatura · 👥 Pareja máx 2 alumnos · 🎓 Tribunal de 3 docentes
